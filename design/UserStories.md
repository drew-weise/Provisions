# Provisions User Stories

## Phase 1: Personal Food Planning Foundation

### Accounts and Privacy

- As a user, I want to create an account so that my food plans, preferences, and history are private to me.

- As a user, I want to sign in securely so that I can return to my saved food data on another device.

- As a user, I want to update or delete my stored preferences so that I stay in control of information used for recommendations.

### Calendar and Food Entries

- As a user, I want to view my food plans on a calendar so that I can see what I intend to eat throughout the day and week.

- As a user, I want to add breakfast, lunch, dinner, snacks, and custom meal categories so that the calendar matches how I actually eat.

- As a user, I want to create a food entry without creating a full recipe so that I can quickly plan simple foods such as a turkey sandwich, cereal, bagel, or snack.

- As a user, I want to add a saved recipe to a meal slot so that I can plan food I intend to cook.

- As a user, I want to add restaurant food, takeout, delivery, grocery-store prepared food, or leftovers to a meal slot so that my calendar reflects real life.

- As a user, I want to leave a meal slot undecided so that I can plan my schedule before deciding what I want to eat.

- As a user, I want to edit, move, replace, or delete a planned food entry so that I can adjust when my plans change.

- As a user, I want to mark a planned meal as completed, skipped, or replaced so that my food history reflects what actually happened.

### Recipes

- As a user, I want to create a recipe manually so that I can save meals I make at home.

- As a user, I want to save recipes with ingredients, amounts, instructions, servings, and tags so that I can use them later.

- As a user, I want to browse and search saved recipes so that I can find food I want to make.

- As a user, I want to favorite recipes so that I can quickly find meals I already know I enjoy.

- As a user, I want to edit or delete my saved recipes so that my recipe library stays accurate.

- As a user, I want to adjust a recipe’s serving size so that ingredient amounts better fit my household.

### Preferences and Constraints

- As a user, I want to save dietary restrictions and allergies so that Provisions does not recommend food that is unsafe for me.

- As a user, I want to record ingredients I dislike or avoid so that recommendations better reflect my preferences.

- As a user, I want to save my household size and typical serving needs so that meal and grocery suggestions are realistic.

- As a user, I want to set a food budget preference so that suggestions can account for what I want to spend.

### Grocery Lists

- As a user, I want to generate a grocery list from my planned home-prepared meals so that I know what ingredients I need to buy.

- As a user, I want grocery lists to exclude restaurant meals, takeout, leftovers, snacks, and prepared foods when they do not require ingredients so that I do not buy unnecessary items.

- As a user, I want to add, edit, check off, and remove grocery-list items manually so that the list works for real shopping trips.

### Conversational Assistant

- As a user, I want to tell the chatbot what I plan to eat so that it can add food entries without making me fill out a form.

- As a user, I want to tell the chatbot when my plans changed so that it can replace or move food entries on my calendar.

- As a user, I want to ask the chatbot to create a meal plan for a day or week so that I can start planning without manually adding every entry.

- As a user, I want the chatbot to explain what it changed before saving it so that I can catch mistakes.

## Phase 2: Grocery, Budget, and Food History

### Food History

- As a user, I want to review what I actually ate in the past so that I can notice patterns in my food habits.

- As a user, I want to see the difference between planned meals and completed meals so that I can make more realistic plans in the future.

- As a user, I want to add notes or ratings to a meal so that Provisions can learn whether I enjoyed it or would choose it again.

- As a user, I want to log leftovers so that I can remember to use food I already have.

### Budgeting

- As a user, I want to record the expected or actual cost of a food entry so that I can understand my food spending.

- As a user, I want restaurant, takeout, grocery, and delivery spending to be categorized separately so that I can see where my money is going.

- As a user, I want to set a food budget for a week or month so that recommendations can help me stay within it.

- As a user, I want to see when a suggested meal fits or exceeds my budget so that I can make an informed choice.

### Grocery Planning

- As a user, I want ingredients from multiple planned meals combined into one grocery list so that I do not buy the same item twice.

- As a user, I want to indicate food I already have at home so that grocery lists do not include ingredients I already own.

- As a user, I want the app to suggest a practical grocery-shopping day based on my upcoming meal plan so that I can shop before I run out of needed food.

- As a user, I want to track grocery-store prepared food separately from ingredients so that a rotisserie chicken or prepared wrap does not become a fake recipe.

### Receipt Scanning

- As a user, I want to upload a receipt or order screenshot so that I do not need to manually type every food purchase.

- As a user, I want Provisions to identify the merchant, date, items, and prices from a receipt so that it can propose grocery, budget, and food-history entries.

- As a user, I want to confirm or correct receipt-scanned information before it is saved so that OCR mistakes do not corrupt my food history or budget.

- As a user, I want to choose whether receipt items become grocery purchases, meal entries, budget transactions, or none of the above so that the app does not make assumptions about every purchase.

## Phase 3: Nutrition and Adaptive Recommendations

### Nutrition

- As a user, I want to set nutrition goals that matter to me so that meal suggestions can consider my priorities.

- As a user, I want to view estimated nutrition information for recipes and meals when available so that I can make informed choices.

- As a user, I want to log food without being forced to track nutrition details so that the application remains useful even when I do not want detailed nutrition tracking.

- As a user, I want to see nutrition trends across planned and completed meals so that I can understand my eating patterns.

### Recommendations

- As a user, I want meal suggestions based on my saved recipes, favorites, past meals, food feedback, budget, schedule, and preferences so that recommendations feel personal.

- As a user, I want recommendations that account for time and energy so that the app does not suggest complicated cooking when I need something easy.

- As a user, I want suggestions that balance home cooking, leftovers, simple foods, takeout, and restaurants so that recommendations reflect real life.

- As a user, I want suggestions that avoid repeating meals too often so that my meal plan has variety.

- As a user, I want Provisions to suggest ways to use groceries I already purchased so that food is less likely to go to waste.

- As a user, I want the app to explain why it recommended a meal so that I can decide whether the recommendation makes sense.

### Preference Learning and User Control

- As a user, I want to tell Provisions when I liked, disliked, skipped, or modified a meal so that future suggestions improve.

- As a user, I want to see the preferences Provisions has learned about me so that I can correct wrong assumptions.

- As a user, I want to remove preferences, food history, or recommendation data so that I control what the application remembers.

- As a user, I want the chatbot to use relevant past feedback when helping me plan food so that I do not need to repeat myself every time.

## Phase 4: Connected Food Services and Households

### External Services

- As a user, I want to connect supported grocery or delivery services so that I can move a grocery list into a shopping cart.

- As a user, I want to import restaurant or delivery orders from supported services so that outside food can be included in my food history.

- As a user, I want to choose exactly which external services can access my information so that integrations remain opt-in.

### Shared Planning

- As a household member, I want to share selected meal plans and grocery lists with other people so that we can coordinate food decisions.

- As a household member, I want to see when another person changes a shared meal plan or grocery list so that we do not make conflicting plans.

- As a household member, I want to keep private food preferences separate from shared household planning when appropriate so that I can control what others see.
